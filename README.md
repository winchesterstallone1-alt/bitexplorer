> **Мощное браузерное расширение для автоматического перехвата аномально выгодных и дешёвых P2P-объявлений на Bybit.**  
> Работает напрямую с активной сессией и cookies браузера, отсекает скам и навязанные комиссии по стоп-словам, строго валидирует лимиты сделки и моментально оповещает звуком и системным push-уведомлением!

---

## ⚡ Особенности и возможности

- 🚀 **Работа в фоне через Service Worker & Cookies**:
  - Расширение использует ваши авторизованные cookies Bybit для безопасных запросов к API.
  - Вкладку Bybit не обязательно держать открытой — радар продолжит сканировать стакан в фоновом режиме.
  - Встроен резервный прокси-мост (Content Script) для гарантированного прохождения Akamai/Cloudflare.

- 💎 **Логика поиска аномально дешевых ордеров**:
  - Автоматически рассчитывает реальную рыночную цену стакана (Benchmark), отсекая единичные аномалии.
  - Сигнализирует, если появляется ордер дешевле рынка на заданную величину (например, рынок по 85.00 ₽, а ордер выставлен по 82.00 ₽).
  - Поддержка трех режимов триггера:
    1. **Дешевле рынка на X ₽/валюты** (абсолютная разница);
    2. **Скидка от рынка на X %** (процентная выгода);
    3. **Фиксированный ценовой порог** (например, цена $\le$ 83.00 ₽).

- 🛡️ **Интеллектуальный фильтр стоп-слов и анти-скам защита**:
  - Полностью исключает объявления с скрытыми условиями в описании (`remark` / `terms`):
    - ❌ *«комиссия 200-300р с покупателя»*
    - ❌ *«3 лицо не принимаю»*, *«от третьих лиц»*
    - ❌ *«только 1 лицо»*, *«только первое лицо»*
    - ❌ *«чек с банкомата»*, *«холд 24ч»*, *«сбер первый»*
  - 🛡️ **Железная защита от маскировки и обфускации (Anti-Leetspeak)**:
    - Ловит хитрые попытки обхода вроде `к0миcciя 6ОО`, `к.о.м.и.с.с.и.я 2ООр`, `к 0 м с а`, `ком-сия 5ООр`.
    - Распознает замену цифр на буквы (`6ОО` вместо `600`, `12ОО` вместо `1200`).
    - Распознает искажения: `3 лuцо`, `3-е л!цо`, `т0льк0 1 л!цо`, `3лицо`.
    - Удаляет невидимые Unicode-символы, нулевые пробелы, разделители и схлопывает искусственные повторы букв.
  - Возможность легко добавлять свои фразы и стоп-слова прямо в панели управления.

- 💵 **Строгая проверка лимитов и дробей сумм**:
  - Задайте вашу целевую сумму обмена (например: **1400 ₽**).
  - Радар покажет только те ордера, в лимиты которых эта сумма гарантированно укладывается ($Min \le 1400 \le Max$).
  - Распознает требования мерчантов вида *«заходите только на суммы 500/1000/2000»* и исключает их, если ваша сумма не подходит.

- 🔔 **Мгновенные оповещения**:
  - **Звуковой сигнал**: синтезируется через Web Audio API (громкий звонкий сигнал, радарный пинг или звук кассы).
  - **Системные Chrome Push-уведомления**: клик по уведомлению сразу открывает карточку сделки на Bybit.
  - **Автоматическое открытие**: опция авто-перехода на страницу ордера для моментального выкупа.

- 🎨 **Киберпанк Bybit Dark UI**:
  - Живая лента пойманных ордеров с расчетом профита.
  - Индикатор состояния куки Bybit (`🟢 Активны` / `🟡 Не найдены`).
  - Быстрый переход в сделку по кнопке.

## 📦 Установка в браузер (Chrome / Brave / Edge / Opera)

1. **Клонируйте репозиторий** или скачайте архив с кодом:
   ```bash
   git clone https://github.com/winchesterstallone1-alt/bitexplorer.git
   ```

2. Откройте в браузере страницу управления расширениями:
   - В Google Chrome: `chrome://extensions/`
   - В Brave: `brave://extensions/`
   - В Microsoft Edge: `edge://extensions/`

3. В правом верхнем углу включите тумблер **«Режим разработчика»** (Developer mode).

4. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked).

5. Выберите папку с проектом (`bitexplorer`).

6. Готово! Иконка радара появится на панели расширений. Рекомендуем закрепить (pin) её.

## 🚀 Как пользоваться

1. **Авторизуйтесь на Bybit**:
   - Откройте [Bybit P2P](https://www.bybit.com/fiat/otc/) в вашем обычном окне браузера и убедитесь, что вы залогинены.
   - Откройте попап расширения — индикатор в шапке покажет `🟢 Куки Bybit активны`.

2. **Задайте параметры во вкладке «Фильтры»**:
   - **Криптовалюта**: `USDT`, `BTC`, `ETH` или `USDC`.
   - **Фиатная валюта**: `RUB`, `KZT`, `BYN`, `USD` и др.
   - **Направление**: Покупка (поиск дешевых предложений) или Продажа.
   - **Ваша сумма**: например `1400` ₽ (программа отсечет всё, где лимиты не совпадают).
   - **Банки**: выберите Т-Банк, Сбербанк, СБП, Райффайзен или «Любой способ».
   - **Критерий выгоды**:
     - *«Дешевле рынка на X ₽»* (например, `1.0` ₽ или `2.0` ₽);
     - Либо укажите фиксированную цену (например: $\le$ `83.00` ₽).
   - Нажмите **«Сохранить настройки»**.

3. **Проверьте стоп-слова во вкладке «Стоп-слова»**:
   - Базовый список уже включает защиту от: `комисси`, `3 лицо`, `только 1 лицо`, `заходите на суммы`, `сбер первый`, `холд` и др.
   - При желании добавьте любые свои фразы через форму ввода.

4. **Запустите радар**:
   - В шапке расширения переведите тумблер в положение **ВКЛ** (загорится зеленый индикатор `РАБОТАЕТ`).
   - Как только в стакане появится выгодное объявление, прозвучит сигнал, всплывет push-уведомление и карточка появится в ленте находок!
